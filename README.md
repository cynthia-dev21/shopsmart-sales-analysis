# ShopSmart Sales Analysis

## Project Overview
End-to-end sales analysis for ShopSmart — a Nigerian 
retail company. Analysed 6 months of sales data to 
identify top performing regions, products and trends.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI
- Google Colab

## Key Findings
- West region generated highest revenue (₦X)
- Laptops were the best selling product
- February was the highest revenue month
- Found and fixed 3 data quality issues

## Skills Demonstrated
- Data cleaning and validation
- Exploratory data analysis (EDA)
- Statistical analysis
- Data visualisation
- Business reporting
